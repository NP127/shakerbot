# ShakeBot

Shake bot (MagicBall) every click will returns a great word of advise

## Installation

1. Clone the repository : `git clone https://github.com/NP127/shakerbot.git`
2. Install dependencies: `npm install`
4. Run app : `nodmon index.js`

## Usage

Use the press the button to generate a word of advise
